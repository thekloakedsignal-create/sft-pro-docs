Part Three · Convert Documents into SFT Examples

The Document Converter lets users upload documents and convert their contents into SFT examples. Each conversion starts with a choice among three conversion types: Knowledge, Transcript, or Literature.

Knowledge conversion

Choose Knowledge to convert document content into knowledge-oriented SFT examples. The UI includes an instructions field where the user can specify what the conversion generator should do with the source material.

Transcript conversion

Choose Transcript when the uploaded document contains a transcript or conversation with speaker turns. The source document must use identifiable role labels so the converter can interpret which role is speaking.

  • When Transcript is selected, the UI displays a dedicated field for entering the role labels used in the document.
  • Enter the source labels, such as user and assistant, matching the document.
  • Use the instructions field to provide any additional directions for the conversion generator.

The role-label field is specific to Transcript conversion. It is separate from the conversion-instructions field.

Literature conversion

Choose Literature to convert literary material into SFT examples. The instructions field lets the user specify requirements for how the conversion generator should handle the source material.

Conversion instructions

All three conversion types provide a field for specific instructions to the conversion generator. Knowledge, Transcript, and Literature each have this field; Transcript additionally has the role-label field.

Document conversion sequence

  1. Upload the document or documents to be converted.
  2. Select Knowledge, Transcript, or Literature.
  3. If Transcript is selected, enter the role labels used in the source document.
  4. Enter any specific conversion instructions.
  5. Run the conversion to create SFT examples.
  6. Review the resulting batch in QA before adding it to the Data Registry.
