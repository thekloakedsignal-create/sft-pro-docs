Part Six · Batch Registry

The Batch Registry collects approved batches and provides the organized set of data assembled for the project. Its workflow is substantially unchanged, but the available templates have expanded.

  • Use the expanded templates available in the current application.
  • Only approved batches are added to the registry.
  • The example type, Instruction or Chat/Multi-Turn, is selected during Project Definition, not in the Batch Registry.

The approved batches in the registry form the collection of data available for the training corpus.
