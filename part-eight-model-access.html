Part Eight · Model Access and Repository Options

Public model

The model produced by Automated Training will be public in the TRiAD Ai public Hugging Face repository.

Transfer to the user's Hugging Face account

The user can transfer the resulting model to their own Hugging Face account. This is optional.

Request removal from the TRiAD Ai public repository

The user may optionally request that the public model be deleted from the TRiAD Ai public repository. The requested removal will be completed within 48 hours.

Transferring the model to the user's own account and requesting removal from the TRiAD Ai public repository are separate options.
