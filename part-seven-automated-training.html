Part Seven · Automated Training

Automated Training follows the Batch Registry. It takes the project's training corpus and validator and runs them through the training pipeline.

Choose a base model

Base model Recommended use
Qwen 3.5 9B Base Recommended overall.
Qwen 3.5 4B Recommended for low-compute local deployment.
Llama 3.1 70B Recommended for hosted deployment and more complex enterprise purposes.

Choose the base model that fits the intended deployment and start the automated workflow. The system automates the training pipeline using the training corpus and validator. When training finishes, the workflow provides a link to the resulting model on Hugging Face.
